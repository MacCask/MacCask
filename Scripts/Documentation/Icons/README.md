# Documentation icon assets

These icons identify Visual Studio Code, Firefox, OBS Studio, VLC, and HandBrake in the rendered demo screenshots. They are copied from their upstream projects and are used only by the documentation renderer; the production app continues to read installed applications' own icons.

Exact source URLs are recorded in [sources.json](sources.json). The application names, icons, and trademarks belong to their respective owners. Upstream asset and brand information:

Visual Studio Code uses the macOS application icon with its rounded white background, matching the application's appearance in a Mac app list.

- [Visual Studio Code branding](https://code.visualstudio.com/brand)
- [Firefox branding resources](https://github.com/mozilla/gecko-dev/tree/master/browser/branding/official)
- [OBS Studio](https://github.com/obsproject/obs-studio)
- [VLC](https://github.com/videolan/vlc)
- [HandBrake](https://github.com/HandBrake/HandBrake)
